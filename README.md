# 📈 Stock Calendar Pro (Gemini AI Enhanced)

Gemini AI 기술을 활용하여 2026년 최신 증시 일정을 자동으로 검색하고 관리하는 스마트 주식 캘린더 솔루션입니다.

## 🌟 주요 기능

### 1. Gemini AI 일정 검색 (AI Search)
- **시장 맞춤형 검색**: 한국(KOSPI/KOSDAQ) 및 미국(NYSE/NASDAQ) 시장을 구분하여 검색합니다.
- **카테고리 필터링**: 공모주(IPO), 배당, 실적 발표, 경제 지표, 휴장일 등 원하는 정보만 선별하여 AI가 찾아줍니다.
- **실시간 데이터 시뮬레이션**: 2026년의 핵심 일정(금리 결정, 대형 IPO 등)을 지능적으로 분석하여 캘린더에 자동 입력합니다.

### 2. 스마트 뷰 관리
- **월간(Monthly)**: 한눈에 보는 한 달 일정.
- **주간(Weekly)**: 시간 흐름에 따른 상세 일정 관리.
- **목록(List)**: 카드 형태로 간편하게 확인하는 일정 리스트.

### 3. 사용자 편의 기능
- **오늘 날짜 자동 강조**: 접속 시 오늘의 날짜를 자동으로 찾고 강조하여 시인성을 높였습니다.
- **상세 정보 모달**: 일정을 클릭하면 주관사, 예상 가격, 상세 수치 등 추가 정보를 바로 확인할 수 있습니다.
- **반응형 디자인**: 다양한 기기 환경에 최적화된 UI를 제공합니다.

## 🛠 기술 스택
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Icons**: Font Awesome 6.0
- **Fonts**: Pretendard Standard
- **Deployment**: Git / GitHub

## 🚀 시작하기
1. 이 저장소를 클론합니다.
2. `index.html` 파일을 브라우저로 엽니다.
3. 좌측 필터에서 원하는 항목을 체크하고 **"필터 적용"**을 눌러 Gemini AI 검색을 체험해 보세요.
